# Pré-Qualificação de Leads — Marcos Antônio (CRECI 11228)

Página web de alta conversão e pré-qualificação de clientes interessados em imóveis para o corretor **Marcos Antônio — CRECI 11228**.

## 🚀 Funcionalidades

- **Tela de Carregamento Fluida (Preloader):** Exibição da logo com barra de progresso suave antes da abertura do questionário.
- **Quiz de 5 Etapas:**
  1. Profissão / Ocupação atual
  2. Restrição no nome
  3. Faixa de renda mensal individual
  4. Casa própria
  5. Estado civil
- **Navegação Inteligente:**
  - Validação de seleção antes de avançar.
  - Botão de retorno preservando a escolha anterior.
  - Modo de edição direta a partir da tela de resumo (retorno sem precisar refazer as etapas).
- **Integração com WhatsApp:**
  - Formatação padronizada e automática da mensagem com todas as respostas.
  - Abertura segura sem dependência de APIs externas pagas.
  - Número de contato centralizado em `js/config.js`.
- **Acessibilidade & Design Responsivo:**
  - Identidade visual minimalista e elegante (paleta quente `#ECE9E4` e preto carvão `#202323`).
  - Totalmente adaptado para dispositivos móveis e desktops.
  - Suporte a navegação por teclado e leitores de tela.

## 🛠️ Tecnologias Utilizadas

- **HTML5** semântico e estruturado para SEO.
- **CSS3** moderno com variáveis (design tokens) e animações fluidas.
- **JavaScript (ES Modules)** puro, leve e de alta performance.

## 📦 Como Executar Localmente

Você pode abrir o arquivo `index.html` diretamente em qualquer navegador ou rodar um servidor local:

```bash
# Com Python
python -m http.server 3000

# Ou com Node.js
npx serve .
```

Acesse em: `http://localhost:3000`
